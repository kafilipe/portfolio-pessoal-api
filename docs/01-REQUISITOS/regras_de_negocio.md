## REGRAS DE NEGÓCIO

- O sistema deve permitir que usuários não autenticados listem e busquem passeios. 
- O sistema deve solicitar autenticação para criação de reservas
- O sistema deve solicitar autenticação para listar reservas existentes
- O sistema deve solicitar autenticação para cancelamento de reservas existentes
- O sistema deve solicitar autenticação para criação de novos passeios
- O sistema deve permitir apenas usuários do tipo cliente a criarem reservas
- O sistema deve permitir apenas usuários do tipo cliente a cancelar reservas
- O sistema deve permitir apenas usuários do tipo administrador a criar novos passeios
- O sistema deve permitir que usuários do tipo administrador listem todas as reservas
- O sistema deve permitir que usuários do tipo cliente listem apenas suas próprias reservas
